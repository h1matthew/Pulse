# Lessons

## 2026-06-15 - Back up slide decks before export work

When editing or finalizing a PPTX, make a timestamped backup of the source deck before any import/export, repair, or overwrite risk. Keep final exports in `outputs/` unless the user explicitly asks to replace the source file.

## 2026-06-15 - Keep deck edits scoped to the requested slide change

When the user asks to keep all slides the same except for one rubric/content addition, do a targeted PPTX edit and verify unchanged slides against the backup. Use rendered slide diffs so the final answer can prove only the intended slide changed.

## 2026-06-15 - Canva is the source of truth for Canva decks

Do not claim a local PPTX is the same as a Canva design unless the live Canva design has been inspected. When the user wants the Canva deck edited, find the actual Canva design, copy it first, and edit the copy rather than relying on local PPTX parity.

## 2026-06-15 - Verify Canva copy parity before editing

After copying a Canva deck, verify the copied pages match the original pages before making edits or sharing the copy link. A copied design is not good enough by itself if the visible slide content shifted or changed.

## 2026-06-15 - Documentation rubric needs visible evidence

For rubric edits, do not only add the rubric keyword to a title. Add visible content that proves the criterion, such as README/setup docs, inline comments, typed contracts, API docs, validation notes, or user-facing help documentation.

## 2026-06-15 - Ask Claude before interpreting its rubric thread

When the user says to ask Claude or references the Claude cowork chat as the source of truth, open Claude and read or ask that thread before making Canva changes. Do not infer the intended slide edit from local docs alone.

## 2026-06-15 - Documentation fix is the real doc plus a slide pointer

For the FBLA documentation rubric row, do not treat a slide label as the deliverable. Create or verify a real README/user guide, then use the slide only to point judges to it. If a slide says "no manual needed," replace that wording because it can imply no documentation exists.

## 2026-06-16 - Make tiny slide/doc changes obvious in the closeout

When the visible slide change is small and most of the work is documentation, say that directly and list the exact changed words, pages, and files. Do not let a "saved" closeout imply a visible redesign when the deck only received wording fixes.

## 2026-06-16 - Give cowork agents time before interrupting

When the user asks another agent, such as Claude, to review something, let that agent run for a reasonable stretch before stopping, nudging, or replacing its response. If it is thinking, wait unless the user asks for an immediate interruption.

## 2026-06-16 - State the Canva copy ID before continuing

When a Canva deck has an original and a copied design, verify and state the copied design ID before any further edits or reviews. Also verify the original design ID separately so the user knows the official deck was not touched.
